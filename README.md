PARKSMART — SMART PARKING MANAGEMENT PORTAL

FILES
- index.html: complete website (HTML, CSS, JavaScript in one file)

HOW TO RUN ON WINDOWS
1. Extract the ZIP file.
2. Open the smart_parking_portal folder.
3. Double-click index.html.
4. It opens in Chrome, Edge, or another browser.

HOW TO USE
1. Select an available green parking slot.
2. Choose vehicle type, enter vehicle number, date, and duration.
3. Press Confirm booking.
4. See the new booking in Recent Bookings.
5. Use the search box to filter booking history.

IMPORTANT
This is a front-end demo. Slot availability and bookings are held in the browser page and reset when the page is refreshed. It does not use a real database, real-time sensors, accounts, or payment processing.
